StewardMem Tools

This installer puts the StewardMem command-line tools on your machine: brain-server (the local memory kernel), brain (the CLI), and mcp (the MCP server), plus optional extras — bench and the connectors.

Nothing is overwritten. If you already run a brain-server service, the new binaries are installed beside it and the installer will tell you exactly what it kept and where. Nothing is installed outside your own home folder, and no administrator password is needed.

You choose what to install on the next screen; Core is pre-selected.
